Normas de Arqueo

1. Todo turno debe iniciarse con un fondo mínimo de sencillo para cambio.
2. Las ventas cobradas con medios digitales (Yape, Tarjetas) se concilian directamente con el comprobante emitido.
3. Al cierre, el sistema contrastará el efectivo físico reportado con el flujo neto esperado (Apertura + Ventas Efectivo - Gastos del Turno).
